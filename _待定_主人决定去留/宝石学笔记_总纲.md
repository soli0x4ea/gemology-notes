# 一、序言

## 1.1 宝石学的定义与研究范围

宝石学（Gemology）是以自然界产出的，具有稀缺、坚硬耐久的无机和有机材料为研究对象，以材料的结构、性质、加工及鉴赏为主要研究内容的综合性自然科学。其中包含了部分晶体学、材料学、矿物学、考古学、哲学及美学的内容。

## 1.2 本笔记的编写原则

| 原则 | 说明 |
|------|------|
| **天然矿物为主体** | 仅研究天然宝石矿物的各项性质，不讨论人工合成或人工处理 |
| **品种独立成篇** | 每种宝石独立成篇，不与其他宝石品类做横向对比 |
| **产地信息保留** | 地质成因属于天然性质的一部分，产地信息可保留 |
| **内含物信息保留** | 天然成因的内含物属于天然性质，可保留 |
| **参考文献规范** | 仅引用学术教材、期刊论文、官方手册；用户笔记与AI对话内容不作为参考文献 |

## 1.3 宝石学的研究框架

```
宝石学
├── 结晶学基础（晶体结构、对称型、空间群）
├── 物理性质（力学、电学、磁性、热学）
├── 光学性质（折射、反射、吸收、发光、旋光性）
├── 便携鉴定仪器（10×放大镜、偏光镜、折射仪、分光镜、紫外灯等）
├── 大型鉴定仪器（FTIR、UV-Vis、XRD、ED-XRF）
└── 宝石各论
    ├── 矿物类宝石（硅酸盐、氧化物、碳酸盐等各大族）
    └── 有机宝石（琥珀、珊瑚、珍珠、象牙等）
```

# 三、便携的珠宝鉴定仪器

> *注：各仪器章节均按以下统一结构编写：*
> *①基本原理 → ②结构与分类 → ③操作方法 → ④读数与判断 → ⑤局限性 → ⑥在主要宝石鉴定中的应用*

## 3.1　10倍放大镜（Jewelers' Loupe）

- 基本原理：折射与表面反射，放大观察宝石表面和内部特征
- 结构：双凸透镜，消色差设计，标准放大倍数 10×
- 操作方法：持镜手法，光源选择（亮域/暗域/侧面光）
- 读数：表面划痕、棱线锋利度、包裹体形态、裂隙充填物特征
- 局限性：放大倍数有限，不适合观察精细包裹体
- 应用：所有宝石鉴定的第一步

## 3.2　偏光镜（Polariscope）

- 基本原理：正交偏振片间的光程差与干涉
- 结构：上偏振片（可旋转）+ 下偏振片 + 光源
- 操作方法：转轮法（旋转上偏振片）+ 锥光法（加干涉球/勃氏镜）
- 四种基本反应：全暗（SR）、全亮（AGG）、斑驳（ADR）、异常干涉图
- 应用：判断晶体系统（等轴/一轴/二轴/非晶质）、光性正负、旋光性、双晶

## 3.3　折射仪（Refractometer）

- 基本原理：全内反射，临界角与折射率的换算
- 结构：折射棱镜 + 标尺 + 光源（589.3nm D线）
- 操作方法：浸液法 / 直接接触法（接触液）
- 读数：折射率（RI）+ 双折射率（DR）+ 光性判断
- 局限性：只测折射率 ≤ 折射仪棱镜折射率（通常 ≤ 1.81）的宝石
- 应用：区分均质体/非均质体、宝石品种初步筛选

## 3.4　分光镜（Spectroscope）

- 基本原理：可见光波段（380–700nm）的吸收光谱
- 分类：棱镜式（色散不均匀）vs 光栅式（色散均匀）
- 操作方法：透射法（观察吸收线）vs 反射法（观察发射线）
- 应用：铬谱、铁谱、锰谱、钴谱、钕谱等特征吸收带
- 局限性：需要经验积累，弱吸收带易遗漏

## 3.5　紫外灯（Ultraviolet Lamp）

- 基本原理：紫外光激发宝石发光，观察荧光颜色与强度
- 分类：长波紫外（LW, 365nm）、短波紫外（SW, 254nm）、长短波双用
- 操作方法：暗室操作，观察荧光颜色、强弱、长短波差异
- 应用：钻石分型（Ⅰ型/Ⅱ型）、红宝石荧光、祖母绿、珍珠、琥珀等

## 3.6　查尔斯滤色镜（Chelsea Color Filter, CCF）

- 基本原理：宽频带滤光，仅透过红光和深红光
- 结构：一片滤色镜，暗红色外观
- 操作方法：暗室操作，白炽灯光源，直接观察
- 读数：绿色反应 / 红色反应 / 无反应
- 局限性：特异性低，多种宝石均可有类似反应，需辅助测试
- 应用：祖母绿（红）、翡翠（红/绿）、红宝石（红）、碧玺（红）

## 3.7　光纤灯 / 全光谱灯（Fibre Optic Light）

- 基本原理：近似日光的连续光谱，辨别宝石真实颜色
- 操作方法：直接照射，观察颜色反应与荧光
- 应用：辅助判断颜色真实性、观察宝石的色带、色块分布

## 3.8　宝石显微镜（Gemological Microscope）

- 基本原理：高倍放大（10×–200×），透射与反射照明
- 分类：卧式（暗域）显微镜、立式（亮域）显微镜
- 照明技术：暗域、亮域、顶部光、偏振光、斜射光、水平光
- 应用：包裹体研究（成因类型）、裂隙充填物、气液包体、生长结构

## 3.9　二色镜（Dichroscope）

- 基本原理：利用冰洲石菱面体将两个振动方向的光并排显示
- 操作方法：眼睛贴近，观察两个并排颜色窗口
- 读数：二色性 / 三色性 / 无多色性
- 局限性：需在合适光线下操作，多色性弱的宝石不易观察
- 应用：红宝石（橙红/紫红）、蓝宝石（蓝/蓝绿）、祖母绿（绿/黄绿）

## 3.10　热导仪（Hygroprobe / Thermal Conductivity Meter）

- 基本原理：导热速度因宝石而异（钻石极高）
- 操作方法：将探头压在宝石表面，读取指示值
- 应用：钻石 / 仿钻的快速区分（钻石读数极高）
- 局限性：无法区分钻石与合成钻石；合成钻石热导率与天然钻石相近

# 四、宝石各论

> *每种宝石品种均按以下统一章节结构编写：*
> *一、概述 → 二、晶体结构 → 三、物理性质 → 四、光学性质 → 五、品种分类与致色机理 → 六、内含物 → 七、产地详情 → 八、参考文献*
>
> *注：水晶（石英）因旋光性为其核心特征，第五章节专设为"旋光性与干涉图"，其余宝石品种统一为"品种分类与致色机理"。*

## 4.1　钻石 Diamond（C）

- 晶系：等轴晶系（4/m -3 2/m）
- 折射率：2.417（全反射临界角 24°24′）
- 解理：4组完全八面体解理
- 硬度：10（自然界最高）
- 颜色：Ⅰa型（黄/褐）、Ⅰb型（少见）、Ⅱa型（无色/粉/褐）、Ⅱb型（蓝）
- 内含物：橄榄岩型（P型）包裹体、榴辉岩型（E型）包裹体
- 产地：澳大利亚、博茨瓦纳、南非、俄罗斯、加拿大等
- 旋光性：无（本征）
- 干涉图：无（本征均质体，但异常双折射常见）
- 耐久性：Excellent（硬度≥8，无解理） | 稀缺性：一般
- **章节结构：八章（标准结构）**

## 4.2　尖晶石 Spinel（MgAl₂O₄）

- 晶系：等轴晶系（4/m -3 2/m）
- 折射率：1.718
- 硬度：8
- 颜色：红色（Cr）、蓝色（Fe）、粉色（Cr+Fe）
- 内含物：八面体负晶、指纹状包裹体、尖晶石自愈裂隙
- 产地：缅甸抹谷、斯里兰卡、越南、塔吉克斯坦等
- 耐久性：Excellent（硬度≥8，无解理） | 稀缺性：稀有
- **章节结构：八章（标准结构）**

## 4.3　石榴石 Garnet（(Ca,Mg,Fe,Mn)₃(Al,Fe,Cr,Ti)₂(SiO₄)₃）

- 晶系：等轴晶系
- 折射率：1.714–1.888（因品种而异）
- 两大系列：铝系石榴石（铁铝榴石、锰铝榴石、镁铝榴石）；钙系石榴石（钙铝榴石、钙铁榴石、钙铬榴石）
- 颜色：铁铝榴石（红褐）、锰铝榴石（橙）、钙铝榴石（绿/黄）、钙铁榴石（翠绿）
- 耐久性：Good（硬度6.5-8，少量解理） | 稀缺性：一般至稀有
- **章节结构：八章（标准结构）**

## 4.4　锆石 Zircon（ZrSiO₄）

- 晶系：四方晶系
- 折射率：1.925–2.015（高折射率宝石之一）
- 硬度：7.5
- 特征：强光泽、强火彩、放射性导致晶格损伤（高型/低型之分）
- 产地：柬埔寨、泰国、斯里兰卡、缅甸等
- 耐久性：Good（硬度6.5-8，少量解理） | 稀缺性：一般
- **章节结构：八章（标准结构）**

## 4.5　刚玉 Corundum（Al₂O₃）

- 晶系：三方晶系，一轴晶负光性
- 折射率：No=1.770, Ne=1.762, DR=0.008
- 硬度：9
- 颜色：红宝石（Cr）、蓝宝石（Fe+Ti）、黄色蓝宝石（Fe³⁺）、粉色蓝宝石（Cr）等
- 内含物：指纹状包裹体、丝绢状金红石针（烧后溶解）、六角形色带
- 耐久性：Excellent（硬度≥8，无解理） | 稀缺性：一般
- **章节结构：八章（标准结构）**

### 4.5.1　红宝石 Ruby
- Cr致色，特征：强红色荧光、深红色调、泰国/缅甸/莫桑比克/斯里兰卡等产地特征差异
- 内含物：指纹状包裹体、泰国八面体熔融包裹体、斯里兰卡糖蜜状包裹体

### 4.5.2　蓝宝石 Sapphire
- Fe/Ti致色（蓝色）、Fe²⁺/Fe³⁺/Cr致色（彩色蓝宝石）
- 产地：克什米尔（丝绒蓝）、缅甸（皇家蓝）、斯里兰卡（矢车菊蓝）、泰国、澳大利亚

## 4.6　绿柱石 Beryl（Be₃Al₂Si₆O₁₈）

- 晶系：六方晶系，一轴晶负光性
- 折射率：No=1.582, Ne=1.576, DR=0.006
- 硬度：7.5–8
- 耐久性：Good（硬度6.5-8，少量解理） | 稀缺性：一般至稀有
- **章节结构：八章（标准结构）**

### 4.6.1　祖母绿 Emerald（Cr致色）
- 特征：深绿色、典型三相包裹体（气液固）、产地差异（哥伦比亚/赞比亚/巴西等）
- 天然内含物：黑云母、黄铁矿、方解石、钠长石（三相包裹体）

### 4.6.2　海蓝宝石 Aquamarine（Fe²⁺致色）
- 颜色：淡蓝至中蓝，Fe含量决定颜色深浅

### 4.6.3　其他绿柱石
- 金绿柱石（Heliodor，Fe³⁺致色，黄色）
- 摩根石（Morganite，Mn致色，粉色）
- 红色绿柱石（Bixbite，Mn致色，深红色，极罕见）

## 4.7　金绿宝石 Chrysoberyl（BeAl₂O₄）

- 晶系：斜方晶系，二轴晶正光性
- 折射率：1.746–1.763
- 耐久性：Excellent（硬度≥8，无解理） | 稀缺性：稀有
- **章节结构：八章（标准结构）**

### 4.7.1　猫眼石 Cat's Eye
- 针状金红石包裹体定向排列，形成猫眼效应
- 颜色：蜜糖色、黄绿色、灰绿色

### 4.7.2　变石 Alexandrite
- Cr致色，日光下绿色，烛光下红色（变色效应）
- 与变色蓝宝石的区别：变石为 Cr 谱，变色蓝宝石为 Fe 谱

## 4.8　电气石 Tourmaline（(Na,Ca)(Mg,Fe,Li,Al)₃Al₆(BO₃)₃Si₆O₁₈(OH)₄）

- 晶系：三方晶系，一轴晶负光性
- 含硼，化学成分复杂导致颜色极其丰富
- 折射率：1.624–1.644
- 耐久性：Good（硬度6.5-8，少量解理） | 稀缺性：一般至稀有
- **章节结构：八章（标准结构）**

## 4.9　单晶石英 Crystalline Quartz（SiO₂）

- 晶系：三方晶系（α-石英）或六方晶系（β-石英），一轴晶正光性
- 旋光性：α-石英为右旋（或左旋），旋光率±12.7°/mm（最强天然旋光矿物之一）
- **旋光性与干涉图（核心章节）**：单晶α-石英在锥光下呈现经典牛眼干涉图（旋转偏振面后的消色线图案）；巴西双晶和道芬双晶导致干涉图异常（螺旋桨形、等色线扭曲），Dauphiné律双晶是旋光性研究的核心案例
- 耐久性：Good（硬度6.5-8，少量解理） | 稀缺性：一般
- **章节结构：五（旋光性与干涉图）为核心，其余七章**

## 4.10　长石族 Feldspar（KAlSi₃O₈ / NaAlSi₃O₈ / CaAl₂Si₂O₈）

- 晶系：单斜晶系（钾长石）/ 三斜晶系（斜长石），二轴晶
- 主要品种：月光石、日光石、天河石、拉长石
- 耐久性：Fair（硬度5.5-7，有明显解理） | 稀缺性：一般
- **章节结构：八章（标准结构）**

## 4.11　橄榄石 Olivine（(Mg,Fe)₂SiO₄）

- 晶系：斜方晶系，二轴晶正光性
- 折射率：1.654–1.690，DR=0.036（强双折射）
- 特征：特征的 Hᵢ 吸收带（蓝区1050nm附近）；内部"睡莲叶"包裹体（应力裂纹+铬铁矿晶体）
- 产地：缅甸、巴基斯坦、中国（河北/吉林）、美国（亚利桑那）
- 耐久性：Good（硬度6.5-8，少量解理） | 稀缺性：一般
- **章节结构：八章（标准结构）**

## 4.12　托帕石 Topaz（Al₂SiO₄(F,OH)₂）

- 晶系：斜方晶系，一轴晶正光性
- 折射率：1.609–1.637
- 硬度：8
- 颜色：无色、蓝色、粉色、黄色、褐色
- 耐久性：Excellent（硬度≥8，无解理） | 稀缺性：一般
- **章节结构：八章（标准结构）**

## 4.13　赛黄晶 Danburite（CaB₂Si₂O₈）

- 晶系：斜方晶系，二轴晶正光性
- 特征：两个光轴 Ng 和 Np 均平行于柱面方向（极为特殊的晶体光学性质）
- 产地：墨西哥、缅甸、日本
- 耐久性：Excellent（硬度≥8，无解理） | 稀缺性：稀有
- **章节结构：八章（标准结构）**

## 4.14　翡翠 Jadeite（NaAlSi₂O₆）

- 晶系：单斜晶系，多晶质集合体
- 结构：纤维交织结构（变晶结构）
- 颜色：绿色（Cr³⁺/Fe³⁺）、白色、紫色等
- 评价：浓、阳、俏、正、匀；起莹（发光感）、起胶（胶质感）、起光（玻璃光泽）
- 产地：缅甸（翡翠唯一宝石级产地）
- **章节结构：八章（标准结构）**

## 4.15　软玉 Nephrite（Ca₂(Mg,Fe)₅Si₈O₂₂(OH)₂）

- 晶系：单斜晶系，多晶质集合体
- 结构：纤维状阳起石/透闪石变晶结构，极为细腻
- 特征：触感细腻如小米粥，韧性好（纤维交织结构所致）
- 产地：中国新疆（和田玉）、青海、俄罗斯、加拿大
- **章节结构：八章（标准结构）**

## 4.16　绿松石 Turquoise（CuAl₆(PO₄)₄(OH)₈·4H₂O）

- 晶系：三斜晶系，常见隐晶质/非晶质集合体
- 折射率：1.61–1.65（隐晶质，多用点测法）
- 特征：孔隙结构，遇水变色（含水量影响颜色）
- 产地：中国湖北（郧西/郧县）、美国（亚利桑那）、伊朗（尼沙布尔）
- **章节结构：八章（标准结构）**

## 4.17　多晶石英 Polycrystalline Quartz（SiO₂）

- 分类：玉髓（致密隐晶质）、玛瑙（带状玉髓）、碧玉（含杂质致色）
- 蛋白石（Opal）：含水无定形SiO₂，变彩效应（光子晶体结构）
- **章节结构：八章（标准结构）**

## 4.18　欧泊 Opal（SiO₂·nH₂O）

- 晶系：非晶质
- 变彩效应：光子晶体结构（球状SiO₂小球规则排列），光衍射产生颜色
- 品种：黑欧泊、白欧泊、火欧泊
- 产地：澳大利亚（90%产量）、埃塞俄比亚、墨西哥
- **章节结构：八章（标准结构）**

## 4.19　琥珀 Amber（C₁₀H₁₆O）

- 晶系：非晶质（有机宝石）
- 偏光镜表现：**天然琥珀几乎都出现异常双折射（ADR）**，由内部应力造成；抚顺琥珀特征：同时具有"不规则消光+显著有规则异常干涉色"（独有条带）；压制琥珀（二代琥珀）：马赛克状/蛇带状消光，边界清晰
- 折射率：1.54（点测法）
- 产地：波罗的海、缅甸、多米尼加、墨西哥、抚顺（中国）
- **章节结构：八章（标准结构）**
