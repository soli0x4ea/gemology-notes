# 为什么利率水平会影响期权的价值

> 编写日期：2026-04-26
> 适用方向：金融学 / 期权定价 / Black-Scholes 模型

---

## 一、核心结论

**利率上升 → 看涨期权（Call）价值上升，看跌期权（Put）价值下降。**

利率下降则相反。这个规律来自两个层面的驱动力：**资金的时间价值**和 **Black-Scholes 定价公式**的数学结构。

---

## 二、第一层逻辑：资金的时间价值

### 2.1 对看涨期权持有者的意义

持有看涨期权，你拥有**以约定价格（行权价 K）买入标的资产的权利**，而非义务。

当利率上升时：

```
资金的时间成本上升

持有现金的人面临更大的机会成本
→ 持有现金等待，不如现在买入股票
→ 看涨期权的吸引力上升
→ 愿意为期权支付更高价格
```

利率上升也意味着**无风险利率（r）上升**，在 Black-Scholes 公式中：
- 股价现值 S₀ 按 e^(rT) 贴现，r 越高 → 贴现因子越小 → S₀·e^(-rT) 更小
- 但行权价 K·e^(-rT) 也同样贴现

### 2.2 对看跌期权持有者的意义

持有看跌期权，你拥有**以约定价格卖出标的资产的权利**。

利率上升时：

```
持有现金的人现在倾向于提前消费或投资
→ 现金留在手中等待行权的吸引力下降
→ 持有现金等待下跌（put获利）的动机减弱
→ 看跌期权价值下降
```

---

## 三、第二层逻辑：Black-Scholes 定价公式的结构

期权价格由以下公式决定（核心项）：

$$C = S_0 N(d_1) - Ke^{-rT} N(d_2)$$

```
C：看涨期权价格
S₀：当前股价
K：行权价
r：无风险利率
T：到期时间
N(d)：标准正态分布累计概率函数
```

**对利率 r 求偏导：**

```
∂C/∂r = K·T·e^(-rT)·N(d₂) > 0

→ 利率 r 上升 → C（Call）上升
```

公式中 **-Ke^(-rT)N(d₂)** 这一项，利率 r 越高，贴现因子 e^(-rT) 越小，整个负项的绝对值越小，因此 C 越大。

对于看跌期权 Put：

$$P = Ke^{-rT}N(-d_2) - S_0 N(-d_1)$$

```
∂P/∂r = -K·T·e^(-rT)·N(-d₂) < 0

→ 利率 r 上升 → P（Put）下降
```

## 四、第三层逻辑：利率与股价的预期关系

利率是宏观经济的"价格信号"：

```
利率上升
  → 企业融资成本上升
  → 经济增长预期下降
  → 股价有下行压力
  → 看涨期权（赌上涨）的价值取决于：
       · 资金成本效应（Call ↑）
       · 股价下行压力（Call ↓）
  → 综合效果：资金成本效应占主导，Call 仍然上升

利率下降
  → 融资成本降低
  → 经济增长预期上升
  → 股价有上行压力
  → 持有现金的机会成本下降
  → 现在持有现金等待更划算
  → Put 价值上升
```

---

## 五、直观举例

假设：股价 S=100，行权价 K=100，到期 T=1年，波动率 σ=20%

| 利率 r | 看涨期权价值 C（估算） | 看跌期权价值 P |
|--------|---------------------|--------------|
| 2% | ≈ 10.5 | ≈ 5.5 |
| 5% | ≈ 11.0 | ≈ 5.0 |
| 10% | ≈ 12.2 | ≈ 4.2 |

> 利率越高 → Call 更值钱（行权价 K 的现值更小，相当于折扣更大）→ Put 相对不那么值钱（持有现金等待下跌的动机减弱）。

---

## 六、利率对期权价值影响的完整图景

```
利率影响期权价值的三条路径：

路径一：资金时间价值
  → 利率↑ → 持有现金的机会成本↑ → Call 吸引力↑ → Call 价值↑
  → 利率↑ → 持有现金等待下跌的收益↓ → Put 吸引力↓ → Put 价值↓

路径二：Black-Scholes 数学结构
  → 利率↑ → Ke^(-rT) 贴现值↓ → 行权成本相对降低 → Call 价值↑

路径三：宏观经济预期
  → 利率变化影响股价预期，进而间接影响期权供需关系
```

## 七、Rho：期权对利率的敏感度

在期权希腊值（Greeks）中，衡量期权对利率敏感度的指标是 **Rho（ρ）**：

| 期权类型 | Rho 符号 | 含义 |
|---------|---------|------|
| 看涨期权（Call） | ρ > 0 | 利率上升 → 期权价值上升 |
| 看跌期权（Put） | ρ < 0 | 利率上升 → 期权价值下降 |

```
ρ_call = K·T·e^(-rT)·N(d₂) > 0
ρ_put  = -K·T·e^(-rT)·N(-d₂) < 0
```

> **注意**：Rho 通常不是最重要的希腊值（Delta 和 Vega 影响更大），但在利率大幅变动的宏观环境下（如美联储加息/降息周期），Rho 的影响不可忽视。

---

**本质总结**：期权是一份**未来交易的权利**，利率决定了"这份未来的权利"在今天值多少钱——未来的钱在今天的购买力、持有现金的机会成本、行权价的贴现值，这些都与利率息息相关。
