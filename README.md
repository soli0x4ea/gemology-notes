# 宝石学系统笔记 · 正式版

## 项目概述

本套笔记系统整理了29种宝石矿物和10篇鉴定仪器/量子光学专题，共39篇正式文档。所有矿物学参数均经Handbook of Mineralogy、Deer, Howie & Zussman《Rock-Forming Minerals》、GIA Gem Reference、Nesse《Introduction to Optical Mineralogy》、Born & Wolf《Principles of Optics》等权威文献交叉验证。

- **正式版发布日期**：2026年7月27日
- **验证轮次**：10轮（第1–9轮宝石矿物、第10轮仪器与量子光学）
- **文件总数**：39篇正式文档 + 3篇辅助文档（序、参考文献、修订记录）

## 阅读建议

1. **入门路径**：序 → 钻石/刚玉/绿柱石/金绿宝石 → 偏光镜/分光镜/放大镜 → 水晶/石榴石/电气石/尖晶石
2. **鉴定实践**：重点阅读第30–35篇仪器文档，配合第1–14篇常见宝石笔记
3. **光学物理深度**：第36–38篇量子光学专题 + 第39篇长石光学计算
4. **数据引用**：所有核心数据以《参考文献》中标注S级的来源为最权威依据
