# 分光镜：结构、原理与宝石学应用

## 一、概述

分光镜（Spectroscope）是宝石鉴定中最常用的小型仪器之一，其核心功能是**观察宝石对可见光的选择性吸收谱**。通过将白光分解为连续光谱，分光镜能够揭示宝石中致色离子（如过渡金属、稀土元素）的特征吸收线或吸收带，从而为宝石品种鉴定、致色机理推断以及处理检测提供关键依据。

与放大镜、折射仪、偏光镜等仪器相比，分光镜的优势在于**无需接触样品、非破坏性、快速直观**。尤其对于具有典型光谱的宝石（如红宝石、祖母绿、橄榄石等），分光镜往往能在数秒内给出决定性提示。

本文将系统介绍分光镜的工作原理、结构分类、操作要领，并重点讨论**不同宝石晶体因其晶体结构、致色离子种类与价态、配位环境等因素所呈现的独特光谱特征**，最后总结其在宝石鉴定中的实际应用与注意事项。

## 二、工作原理

### 2.1 物理基础：光的色散与选择性吸收

白光（连续光谱）通过宝石时，宝石中存在的致色离子会吸收特定波长的光子，导致相应波长的光强减弱，在连续光谱上留下**吸收线（窄带）** 或**吸收带（宽带）**。这些吸收特征的位置、强度、形状由致色离子的能级结构决定，因此具有**指纹性**。

分光镜的核心任务是将经过宝石吸收后的复合光分解为单色光，使观察者能够直接看到光谱中的缺失部分。

### 2.2 色散元件：棱镜与光栅

分光镜利用色散元件实现光的分解，主要分为两类：

1.  **棱镜式分光镜**：采用三角棱镜（通常为多个棱镜组合）基于**折射率随波长变化**的原理（正常色散）将光展开。其光谱特点为蓝紫区展宽较明显，红光区压缩且分辨率较低。
2.  **光栅式分光镜**：采用衍射光栅基于**衍射干涉**原理将光展开。其光谱各色区宽度大致相等，红光区分辨率高于棱镜式，且谱线更直、更清晰。

### 2.3 工作光路

典型的分光镜光路如下（以棱镜式为例）：
1.  **入射狭缝**：限制进入光线的宽度，提高光谱分辨率。
2.  **准直透镜**：将来自狭缝的发散光变为平行光束。
3.  **色散元件**（棱镜/光栅）：将平行白光按波长展开。
4.  **聚焦透镜/目镜**：将色散后的光谱成像于焦平面（或直接进入人眼）。

## 三、结构分类

### 3.1 手持式（便携式）分光镜

- **重量**：通常 100‑200 g，便于野外或市场使用。
- **光源**：需外接连续白光光源（如白炽灯、光纤灯）。
- **典型型号**：GEM‑4（光栅式）、GIA 棱镜式分光镜等。

### 3.2 台式（电子）分光镜

- **集成度**：内置光源、样品台、光电传感器或 CCD 相机。
- **输出**：光谱实时显示于电脑屏幕，可数字化存储、分析。
- **优势**：解放人眼、便于弱光谱观测、可进行定量分析。
- **典型型号**：MKY‑FTS‑CCD 等。

### 3.3 棱镜式 vs. 光栅式对比

| 特征 | 棱镜式 | 光栅式 |
|------|--------|--------|
| **色散原理** | 折射 | 衍射 |
| **光谱均匀性** | 蓝紫区宽，红光区窄 | 各色区宽度均匀 |
| **红光区分辨率** | 较低 | 较高 |
| **光谱线形** | 略弯曲 | 直 |
| **价格** | 相对较低 | 相对较高 |
| **维护** | 棱镜易受污染 | 光栅怕磕碰 |

## 四、使用方法

### 4.1 透射法（适用于透明‑半透明宝石）

1.  将宝石置于光源上方，使光**透过**宝石。
2.  分光镜狭缝对准宝石透射光区域。
3.  眼睛贴近目镜，调节焦距直至光谱清晰。
4.  记录吸收线/带的位置、强度、形状。

### 4.2 反射法（适用于不透明或透明度差的宝石）

1.  将宝石放在黑色背景上。
2.  用光源以约 **45°** 角照射宝石表面。
3.  分光镜狭缝对准宝石表面的**反射光**，分光镜本身也呈约 45° 角。
4.  观察记录。

### 4.3 关键操作要点

- **光源**：必须使用**连续光谱白光源**（白炽灯、卤素灯），**禁止使用 LED 灯**（发射线状光谱）。
- **狭缝清洁**：灰尘会在光谱上产生黑色水平干扰线。
- **样品转动**：转动宝石可增加光程，增强弱吸收线的可见度。
- **避免过热**：强光长时间照射可能导致吸收线模糊甚至消失。
- **综合鉴定**：分光镜结果需与折射率、比重、显微镜等数据结合判断。

## 五、宝石光谱特征：不同晶体的“指纹”

宝石的光谱特征直接反映其**晶体结构**、**致色离子种类与价态**、**配位对称性**以及**晶体场强度**等微观信息。以下列举典型宝石的光谱特征，并简要讨论其物理成因。

### 5.1 红宝石（Cr³⁺ 致色）

- **主要吸收线**：
  - **694 nm**、**692 nm**（红光区双线，Cr³⁺ 的 **²E→⁴A₂** 跃迁）
  - **668 nm**、**659 nm**（红光区较弱双线）
  - **620 nm** 附近吸收带（黄‑橙区）
  - **476 nm**、**475 nm**（蓝区双线）
  - **468 nm**（蓝区）
- **蓝紫区**：强吸收带（<450 nm），导致红宝石在蓝紫光透过率极低，呈现红色。
- **成因**：Cr³⁺ 进入刚玉（Al₂O₃）八面体格位，在晶体场作用下 d 轨道分裂，产生上述特征跃迁。

### 5.2 蓝宝石（Fe²⁺/Ti⁴⁺ 电荷转移致色）

- **主要吸收带**：
  - **450 nm**（蓝区，最强）
  - **460 nm**、**470 nm**（蓝区，伴线）
- **黄‑绿区**：较宽吸收带，导致蓝宝石在黄‑绿光区域透过率较低。
- **成因**：Fe²⁺ 与 Ti⁴⁺ 之间发生**电荷转移**，所需能量对应于蓝‑黄光吸收。

### 5.3 祖母绿（Cr³⁺/V³⁺ 致色）

- **主要吸收线**：
  - **683 nm**、**680 nm**（红光区双线，Cr³⁺）
  - **637 nm**（红光区）
  - **606 nm**（橙区）
  - **430 nm**（紫区，V³⁺ 贡献）
- **红光区**：有时可见 **683 nm** 与 **680 nm** 之间的**干涉条纹**（因祖母绿常含平行管状包裹体）。
- **成因**：Cr³⁺（及少量 V³⁺）进入绿柱石（Be₃Al₂Si₆O₁₈）的 Al³⁺ 八面体格位，晶体场强度略低于红宝石，导致吸收线位置略有偏移。

### 5.4 橄榄石（Fe²⁺ 致色）

- **三个强吸收带**（“橄榄石三带”）：
  - **453 nm**（蓝紫区）
  - **477 nm**（蓝区）
  - **497 nm**（蓝‑绿区）
- **整体特征**：蓝‑绿区吸收强烈，黄‑红光透过率高，故呈黄绿色。
- **成因**：Fe²⁺ 占据橄榄石（Mg,Fe)₂SiO₄ 中 M1 与 M2 两种八面体格位，晶体场分裂不同，形成三个重叠的宽吸收带。

### 5.5 翡翠（硬玉，Cr³⁺/Fe³⁺ 致色）

- **Cr³⁺ 致色（翠绿色）**：
  - **691 nm**、**655 nm**、**630 nm** 吸收线（红光区）
  - **437 nm** 吸收线（紫区）
- **Fe³⁺ 致色（绿‑灰绿色）**：
  - **450 nm** 附近宽吸收带（蓝区）
  - **630‑690 nm** 区间弱吸收
- **成因**：Cr³⁺ 取代硬玉（NaAlSi₂O₆）中 Al³⁺；Fe³⁺ 同样进入格位，但晶体场跃迁能量不同。

### 5.6 变石（金绿宝石，Cr³⁺ 致色）

- **主要吸收带**：
  - **680 nm** 附近强吸收带（红光区）
  - **580 nm** 附近吸收带（黄‑绿区）
  - **470 nm** 附近吸收带（蓝区）
- **“变石效应”解释**：Cr³⁺ 在金绿宝石（BeAl₂O₄）中处于低对称性格位，吸收带位置恰好位于可见光谱中间。日光（蓝‑绿光多）下蓝‑绿光被吸收，呈现红色调；白炽灯（红光多）下红光被吸收，呈现绿色调。

### 5.7 稀土致色宝石（如磷灰石、萤石）

- **特征**：出现**密集、尖锐的吸收线**（稀土离子的 **f‑f** 跃迁受晶体场影响小，线宽窄）。
- **典型示例**：磷灰石（Nd³⁺）在 **580 nm**、 **745 nm** 等多处出现尖锐吸收线。

### 5.8 小结：光谱与晶体结构的关联

1.  **晶体场强度**影响吸收峰位置：同一致色离子在不同晶体中，因配位数、键长、对称性不同，晶体场分裂能 Δ 不同，导致吸收峰波长偏移。
2.  **格位对称性**影响谱线数目与形状：高对称性（如八面体）下 d‑d 跃迁选律允许的谱线较少；低对称性（如变石中的 Cr³⁺）可能解除简并，出现更多吸收带。
3.  **电荷转移**与 **d‑d 跃迁**的区分：电荷转移吸收通常强度高、带宽大（如蓝宝石的 Fe²⁺‑Ti⁴⁺）；d‑d 跃迁相对较弱、带宽较窄（如红宝石的 Cr³⁺）。
4.  **稀土离子**的 f‑f 跃迁几乎不受晶体场影响，谱线尖锐、位置稳定，是鉴定含稀土宝石的重要指纹。

## 六、鉴定应用

### 6.1 品种鉴定

- **快速筛查**：对具有典型光谱的宝石（红宝石、祖母绿、橄榄石、变石等），分光镜可提供近乎决定性的证据。
- **区分相似品种**：例如，红色尖晶石与红宝石光谱相似但细节不同；绿色碧玺与祖母绿光谱差异明显。

### 6.2 致色机理推断

- **判断致色离子**：Cr³⁺、Fe²⁺/Fe³⁺、稀土等具有特征光谱。
- **辅助产地推测**：某些产地的宝石因微量元素组合独特，光谱略有差异（如克什米尔蓝宝石在 450 nm 吸收带较弱）。

### 6.3 处理检测

- **染色处理**：有机染料吸收带通常宽而模糊，且多位于绿‑红区。
- **镀膜/填充**：异常吸收带或全光谱减弱。
- **热处理**：可能导致某些吸收线减弱或消失（如某些蓝宝石经过高温处理后 450 nm 吸收带减弱）。

### 6.4 合成与天然鉴别

- **维尔纳叶法合成红宝石**：因生长条件差异，可能缺失天然红宝石中某些弱吸收线。
- **助熔剂法合成祖母绿**：光谱与天然祖母绿极相似，需结合包裹体等特征。

## 七、注意事项与局限性

1.  **光源必须为连续光谱**：白炽灯、卤素灯最佳，禁用 LED、荧光灯。
2.  **样品大小与颜色**：太小、太浅或太深的宝石可能难以观测到吸收线。
3.  **仪器分辨率**：低分辨率分光镜可能无法分辨紧密的双线（如红宝石 694/692 nm）。
4.  **人为因素**：观察者经验、眼疲劳会影响判断。
5.  **非万能**：许多宝石（如钻石、水晶、托帕石）在可见光区无明显吸收，分光镜无法提供有效信息。
6.  **综合鉴定原则**：分光镜结果必须与其它仪器（折射仪、显微镜、紫外灯等）结合，避免单一依据误判。

## 八、结论

分光镜作为宝石鉴定中的“光谱显微镜”，通过揭示宝石对可见光的选择性吸收，将微观的晶体场、能级跃迁信息转化为直观的光谱图案。不同宝石晶体因其晶格结构、致色离子类型与价态、配位环境的不同，呈现出独一无二的“光谱指纹”。掌握分光镜的原理与操作，并熟悉常见宝石的光谱特征，是宝石鉴定师不可或缺的核心技能。

随着电子分光镜、光纤光谱仪等数字化设备的普及，分光镜的观测精度与数据保存能力不断提升，但其基本原理与鉴定逻辑不变——**光与物质的相互作用，始终是理解宝石颜色与鉴定本质的物理基础**。
