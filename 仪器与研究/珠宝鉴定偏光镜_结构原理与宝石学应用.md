## 一、概述

偏光镜（Polariscope）是宝石学中最重要的非破坏性检测工具之一，通过分析偏振光在宝石中的行为，可以快速判断宝石的晶体结构、光学性质和真伪。本篇从两个层面解析偏光镜：

1. **量子力学层面**：光的偏振本质、光子的偏振态、偏振片的选择机制
2. **宝石学层面**：偏光镜的结构、四大光学反应、干涉图观察、光性正负判定，以及具体宝石品种的应用案例

## 二、偏振现象的量子力学解释

### 2.1 光作为电磁波

光是电磁波，由相互垂直的电场矢量 **E** 和磁场矢量 **B** 沿传播方向振荡传播。普通光源（非偏振光）的电场矢量在垂直于传播方向的平面内**各方向等概率振动**，形成大量振动方向杂乱的普通光。

```
普通光（非偏振光）：

传播方向 →（垂直于纸面向外）
电场矢量 E 随机指向平面内各个方向
（→ ↗ ↑ ↙ ← ↙ ↓ ↘ → … 等概率）

偏振光（平面偏振光）：

传播方向 →（垂直于纸面向外）
电场矢量 E 仅沿单一方向振动
（例如：仅水平方向 →→→→）
```

### 2.2 光子：自旋-1 粒子的偏振量子态

从量子力学角度，光子是**自旋为 1 的无质量基本粒子**。其偏振态可以用二维复希尔伯特空间描述，与电子自旋的情形类似。

#### 2.2.1 偏振基矢

两种最常用的偏振基：

```
线偏振基：                    圆偏振基：
|H⟩ = 水平偏振                |R⟩ = 右旋圆偏振
|V⟩ = 垂直偏振                |L⟩ = 左旋圆偏振

正交性：⟨H|V⟩ = 0             |R⟩ 和 |L⟩ 互为正交基
归一化：⟨H|H⟩ = ⟨V|V⟩ = 1
```

#### 2.2.2 偏振态的数学表示

任意光子的偏振态可以表示为两个基态的**叠加**：

$$|\psi\\rangle = \\alpha|H\\rangle + \\beta|V\\rangle$$

其中 α, β 为复振幅，满足归一化条件：

$$|\\alpha|^2 + |\\beta|^2 = 1$$

**物理意义**：
- |α|² = 测量到水平偏振的概率
- |β|² = 测量到垂直偏振的概率

> 这正是量子态叠加原理的核心：测量前，光子同时处于 |H⟩ 和 |V⟩ 的叠加态，测量导致波函数坍缩到确定的本征态。

#### 2.2.3 光子的自旋角动量

光子携带**自旋角动量（Spin Angular Momentum, SAM）**，其投影沿传播方向只能取两个值（+ħ 或 -ħ），分别对应左旋和右旋圆偏振。这与电子自旋不同——电子的自旋投影可以是 +ħ/2、0（不沿给定方向）或 -ħ/2（三个值），而光子只有两个。

```
圆偏振的自旋角动量：
右旋圆偏振（RCP）→ 自旋角动量 = +ħ（平行于传播方向）
左旋圆偏振（LCP）→ 自旋角动量 = -ħ（反平行于传播方向）
```

### 2.3 偏振片如何"选择"光子

这是理解偏光镜工作原理的量子核心。偏振片（Polarizer）本质上是一个**测量装置**——它测量每个光子的偏振方向，并选择性地透过或吸收。

#### 偏振片的物理实现

现代偏光片通常由含有**二色性分子**的拉伸聚乙烯醇（PVA）塑料制成。这些分子排列成长链，长链方向即为偏振片的**透射轴**。分子链选择性地吸收垂直于链方向的电场振动，仅允许沿链方向振动的光通过。

```
偏振片内部结构示意：

⊃⊃⊃⊃⊃⊃⊃⊃  ← 大量长链分子排列成方向
⊃⊃⊃⊃⊃⊃⊃⊃
⊃⊃⊃⊃⊃⊃⊃⊃  ← 此方向 = 透射轴方向

电场振动方向与透射轴一致 → 透过
电场振动方向与透射轴垂直 → 吸收
斜向振动 → 仅透过投影分量（强度按 cos²θ 衰减）
```

#### 偏振片的量子力学处理

理想偏振片可视为一个**投影算子** $\\hat{P}_{\\text{axis}}$，将入射态投影到透射轴方向：

$$|\\psi\\rangle = \\alpha|H\\rangle + \\beta|V\\rangle \\xrightarrow{\\hat{P}_{H}} \\alpha|H\\rangle$$

从概率视角：入射光子以概率 cos²θ 透过（偏振方向与透射轴夹角为 θ），以概率 sin²θ 被吸收或反射。

#### 马吕斯定律的量子解释

马吕斯定律（Malus' Law）表述为：

$$I = I_0 \\cos^2\\theta$$

这实际上是大量光子的**统计结果**——在大量测量事件中，与透射轴成 θ 角的光子，其偏振方向在透射轴方向的投影振幅为 cosθ，因此透过概率为 cos²θ。

### 2.4 庞加莱球：偏振态的几何表示

经典光学用**庞加莱球（Poincaré Sphere）**表示纯偏振态——球面上的每一点对应一种偏振态（赤道代表线偏振，两极代表左/右旋圆偏振）。

量子力学中，**量子偏振度**（Quantum Degree of Polarization）在三维庞加莱空间中用嵌套球表示，反映了不同偏振态之间的量子关联。经典方法将所有偏振态映射到单一球面，而量子处理揭示了更精细的结构——特别是对于非经典态（如压缩态、单光子态）。

```
庞加莱球简化示意：

        LCP（|L⟩）
         ★
        /|\\
       / | \\
      /  |  \\
    赤道：线偏振（H/V/斜向）
    ↓
    球心 = 完全非偏振光
```

### 2.5 双折射的量子力学本质

当偏振光进入各向异性晶体（如红宝石、蓝宝石）时，光被分解为两束——这不是光的"分裂"，而是量子力学中的**本征态分裂**：

- 晶体中，电子的势能环境具有方向依赖性
- 光子感受到的折射率随振动方向变化
- 两个振动方向对应两个不同的本征能量/动量
- 解出的两个本征偏振态即为晶体的两个**主振动方向**（principal vibration directions）
- 这两个方向的光在晶体中具有不同的相速度，因此以不同速度传播，产生**光程差**

```
双折射过程（量子视角）：

入射偏振光 |ψ⟩ = α|o⟩ + β|e⟩   （|o⟩=Ordinary常光，|e⟩=Extraordinary非常光）
    ↓
进入各向异性晶体
    ↓
分解为两个本征态，各自以不同相速度传播
    ↓
两束光产生光程差 δ = (n_e - n_o) × d（d = 晶体厚度）
    ↓
重新通过检偏镜时，两束光发生干涉，产生干涉色
```

## 三、偏光镜的结构与工作原理

### 3.1 基本结构

```
偏光镜构造示意图（侧面视图）：

            分析镜（Analyzer）
            可旋转，可调至亮位/暗位
         ╔═══════════════════════╗
         ║─────────────────────────║
         ╚═══════════════════════╝
              ↑
         旋转宝石（或旋转检偏镜）
              ↓
         ╔═══════════════════════╗
         ║  宝石（宝石夹持具）   ║
         ╚═══════════════════════╝
              ↑
         偏振器（Polarizer）
         固定不动，包含光源和漫射板
         ╔═══════════════════════╗
         ║  ● 光源（LED/灯泡）   ║
         ║  ○ 漫射板             ║
         ╚═══════════════════════╝
```

| 组件 | 名称 | 功能 |
|------|------|------|
| 下方 | **偏振器（起偏镜）** | 固定不动，将普通光变为平面偏振光，含光源和漫射板 |
| 中间 | **宝石载台** | 放置宝石，可手动旋转 |
| 上方 | **分析镜（检偏镜）** | 可旋转，用于检测透出光的偏振状态 |
| 可选附件 | **锥光镜（Conoscope）** | 小玻璃球，置于宝石上方，用于观察干涉图 |
| 可选附件 | **补色片（Compensator）** | 石膏板（550nm）、云母板（1/4λ）、石英楔，用于判断光性正负 |

### 3.2 正交偏光与消光位置

当上、下两个偏振片的透射轴方向**垂直**（相差90°）时，光线无法通过，视野全暗——这称为**正交偏光**或**消光位置（Extinction）**。

```
消光位置示意：

下方偏振器（透射轴水平 →）：
  光线通过，振动方向水平
  
上方偏振器（透射轴垂直 ↑）：
  垂直方向 ← 无法通过 → 全暗

旋转90°后（亮位）：
  上方偏振器透射轴变为水平 →
  光线通过 → 全亮
```

### 3.3 偏光镜的工作流程

```
步骤 1：将两个偏振片调至正交（消光位置），视野全暗

步骤 2：放置宝石在载台上

步骤 3：旋转宝石（或旋转检偏镜），观察宝石的反应

步骤 4：根据反应类型（见第四章）判断宝石的光学性质

步骤 5（可选）：加入锥光镜观察干涉图，判断单轴/双轴和光性正负
```

## 四、四大光学反应与宝石分类

### 4.1 四种基本反应

宝石在正交偏光下旋转 360°，可能出现以下四种反应：

| 反应类型 | 旋转360°的观察结果 | 代表宝石 | 晶体系统 | 光学性质 |
|---------|-------------------|---------|---------|---------|
| **SR（单折射）** | 全暗（始终黑暗） | 石榴石、尖晶石、玻璃、钻石、欧泊 | 等轴晶系 | 各向同性 |
| **DR（双折射）** | 四明四暗（闪烁4次） | 红宝石、蓝宝石、石英、橄榄石、碧玺、托帕石 | 六方/四方/斜方/单斜/三斜晶系 | 各向异性 |
| **AGG（集合体）** | 全亮（始终明亮） | 翡翠（硬玉）、软玉、玉髓、玛瑙 | 微晶/隐晶质集合体 | 大量随机方向的微小晶体 |
| **ADR（异常双折射）** | 不规则明暗变化、蛇形条纹、粗布纹状斑驳 | 石榴石、尖晶石、玻璃、琥珀、CVD合成钻石 | 本质各向同性，但内部有应变 | 应变各向异性 |

### 4.2 单折射（SR）详解

**原理**：等轴晶系宝石和玻璃为非晶质，光在其中沿任何方向传播速度相同，不改变偏振光的振动方向，因此在正交偏光下始终消光。

**操作要点**：
- 需从至少 3 个不同方向测试（宝石沿光轴方向观察时也会全暗）
- 高折射率宝石（如钻石）台面朝下时可能发生全内反射，需将宝石侧放（亭部朝上贴偏光镜）

### 4.3 双折射（DR）详解

**原理**：非等轴晶系宝石具有各向异性，光进入后被分解为两束振动方向相互垂直的偏振光，这两束光的传播速度不同，穿过检偏镜时产生明暗交替。

**典型现象**：
- 旋转 360° 出现 4 次明暗交替（四明四暗）
- 明暗交界处出现移动的**黑刷（Isogyre/Brush）**
- 有时宝石同时出现明区和暗区，形成特殊光纹

### 4.4 聚合体（AGG）详解

**原理**：微晶质或隐晶质宝石（如翡翠）由无数微小晶体随机排列组成。每个微晶都使光偏振，但由于方向随机，总会有部分光能透过检偏镜——因此在所有旋转角度下均保持明亮。

**鉴定意义**：翡翠在偏光镜下始终明亮是鉴定其天然性的重要依据之一。

### 4.5 异常双折射（ADR）详解

**产生原因**：本征单折射宝石（如石榴石、尖晶石）内部存在晶格扭曲、应力分布不均匀、固体包裹体或空洞，导致局部偏振效应。

**特征识别**：
- 明暗变化**不规则**，无四明四暗的规律
- 常表现为：黑色不规则条纹、粗布纹状斑驳、中心出现黑色十字（但无干涉色）
- 严重应变时（如某些琥珀、钻石）可在任何方向出现斑驳干涉色

**区分 ADR 与真双折射的技巧**：
1. 将宝石旋转至最亮位置
2. **快速将检偏镜旋转 90°**（偏离暗场）
3. 观察：如果宝石明显**变亮** → ADR（单折射宝石）；如果**亮度不变或变暗** → 真双折射

## 五、干涉图的观察与分析

### 5.1 锥光镜的作用

在偏光镜上方添加锥光镜（无应变的小玻璃球），将发散的偏振光会聚后通过宝石，使三维的干涉现象转化为二维图像——这就是**干涉图（Interference Figure）**。

```
锥光镜操作步骤：
1. 在正交偏光下旋转宝石，寻找"彩色闪光"（干涉色）
2. 找到后固定宝石
3. 将锥光镜悬停于宝石上方
4. 彩色闪光扩展为圆形干涉图
```

### 5.2 单轴晶干涉图

**出现条件**：六方晶系、四方晶系、菱方晶系宝石（红宝石、蓝宝石、碧玺等）。

**典型图样**：被黑十字交叉的**同心彩色圆环**。

- 黑十字中心（梅拉托普，Melatope）代表**光轴方向**
- 色圈越密 → 双折射率越高
- 色圈越疏 → 双折射率越低

```
单轴晶干涉图示意：
     ╋ ← 黑十字
   ╭─╮
  ╱ ◎ ╲  ← 同心彩色圆环
 ╱─╮ ╭─╲
╱◎ ╲╱ ╲◎╲
────╋────  ← 梅拉托普（光轴）
```

### 5.3 双轴晶干涉图

**出现条件**：斜方晶系、单斜晶系、三斜晶系宝石（橄榄石、金绿宝石、坦桑石等）。

**典型图样**：两个光轴方向，黑十字分离为双曲线形黑带（等色线），45° 位置时弯曲度最大。

```
双轴晶干涉图示意：
    ╱╲
   ╱ ╲    ← 双曲线等色线
  ╱  ╲
  ˙    ˙  ← 两个光轴位置
```

**2V角**：两个光轴之间的夹角，2V值较大（>40-50°）时难以在同一视野看到两个光轴。

### 5.4 石英的特殊干涉图：牛眼图

石英晶体因具有左/右旋手性结构，在锥光镜下呈现独特的**牛眼图（Bull's Eye）**——十字交叉于中心的绿色或紫红色同心圆环。

**进阶观察**：加入 1/4 波片（137nm）后，牛眼图变为向左或向右旋转的**艾里螺旋（Airy's Spiral）**，用于判断石英的左右手型。若紫水晶显示 4 个螺旋，则为**巴西双晶（Brazilian Twin）**。

### 5.5 一轴晶与二轴晶的快速判断

```
旋转宝石寻找干涉色
        ↓
消光影（等色线）不弯曲 → 单轴晶
消光影（等色线）弯曲 → 双轴晶
```

## 六、光性正负的测定

### 6.1 基本原理

通过在光路中插入**补色片（Compensator）**改变光程差，观察干涉色的变化方向来判断光性正负。

**常用补色片**：
| 类型 | 延迟量 | 用途 |
|------|--------|------|
| 石膏板（石膏试板） | 550nm（全波片） | 一轴晶光性正负判定 |
| 云母板 | 137nm（1/4波片） | 一轴晶快速判定 |
| 石英楔 | 连续变化 | 二轴晶光性正负判定 |

### 6.2 一轴晶光性判定（石膏板法）

1. 找到单轴干涉图
2. 将石膏板插入分析镜与宝石之间，置于 **45° 位置**
3. 观察十字交叉附近的四个象限颜色变化：

| 颜色变化 | 光性 |
|---------|------|
| 1、3象限变**蓝**，2、4象限变**黄橙** | 一轴晶**负光性（Uniaxial Negative）** |
| 1、3象限变**黄橙**，2、4象限变**蓝** | 一轴晶**正光性（Uniaxial Positive）** |

> **记忆技巧**：蓝在"负极"（2、4象限在椭圆长轴两端）→ 负光性。

### 6.3 一轴晶光性判定（云母板法）

1. 找到单轴干涉图
2. 插入云母板（1/4波片）
3. 观察出现的两个黑点位置：

| 黑点位置 | 光性 |
|---------|------|
| 黑点在 1、3象限 | 一轴晶**正光性** |
| 黑点在 2、4象限 | 一轴晶**负光性** |

### 6.4 二轴晶光性判定（石英楔法）

1. 找到双轴干涉图
2. 将石英楔从等色线最凹侧向最凸侧移动
3. 观察等色线移动方向：

| 等色线移动方向 | 光性 |
|--------------|------|
| 向另一个光轴（视野外）移动 | 二轴晶**正光性** |
| 背离另一个光轴移动 | 二轴晶**负光性** |

## 七、偏光镜在宝石鉴定中的具体应用案例

### 7.1 钻石

| 宝石 | 偏光镜反应 | 意义 |
|------|-----------|------|
| 天然钻石（无应变） | 全暗（SR） | 各向同性 |
| 天然钻石（有应变） | 不规则斑驳（ADR） | 内部应力，可能是罕见天然应变或处理迹象 |

> **实用提示**：大多数天然钻石在偏光镜下表现为全暗或轻微 ADR。强烈不规则干涉色图案需进一步调查原因（可能是处理或钻石的异常应变）。

### 7.2 红宝石、蓝宝石

| 宝石 | 偏光镜反应 | 意义 |
|------|-----------|------|
| 天然红宝石/蓝宝石 | 四明四暗（DR），十字干涉图 | 各向异性，一轴晶 |
| 双晶蓝宝石 | 全亮（AGG）或不规则反应 | 巴西双晶导致大量随机晶界 |

### 7.3 祖母绿

| 宝石 | 偏光镜反应 | 意义 |
|------|-----------|------|
| 天然祖母绿 | 四明四暗（DR） | 各向异性，一轴晶负光性 |
| 玻璃充填祖母绿 | 愈合裂纹周围可见应变 | 处理鉴定的辅助依据 |

### 7.4 碧玺（Tourmaline）

碧玺是典型的一轴晶宝石，锥光镜下显示清晰的十字干涉图。

| 特征 | 表现 |
|------|------|
| 偏光反应 | 四明四暗（DR） |
| 干涉图 | 单轴十字图，色圈密度与双折射率相关 |
| 多色性检测 | 偏光镜亮位下旋转可观察颜色变化（但二色镜更精确） |

### 7.5 石英（Quartz）与水晶

| 宝石 | 偏光镜反应 | 意义 |
|------|-----------|------|
| 天然水晶/紫水晶 | 四明四暗（DR），牛眼干涉图 | 单轴晶正光性 |
| 巴西双晶紫水晶 | 加 1/4 波片显示 4 个艾里螺旋 | 判断双晶的重要依据 |
| 玉髓（微晶石英） | 全亮（AGG） | 隐晶质集合体的天然标志 |

### 7.6 橄榄石（Peridot）

橄榄石是典型的一轴晶宝石：

| 特征 | 表现 |
|------|------|
| 偏光反应 | 四明四暗（DR） |
| 干涉图 | 单轴十字图 |
| 典型内含物 | 铬铁矿晶体 + 应力晕（10×放大镜下可见） |

### 7.7 石榴石（Garnet）家族

石榴石为等轴晶系，理论上应为单折射（SR），但多种石榴石表现出强烈的异常双折射：

| 石榴石品种 | 偏光镜反应 | 特点 |
|-----------|-----------|------|
| 铁铝榴石（Almandine） | 强 ADR | 常显示不规则黑色斑驳 |
| 钙铝榴石（Grossular） | 弱至中等 ADR | 某些变种可能有明显反应 |
| 锰铝榴石（Spessartine） | SR 或弱 ADR | 因产地而异 |
| 翠榴石（Demantoid） | SR | ADR 不明显 |
| 沙弗莱（Tsavorite） | SR | ADR 不明显 |

> **重要**：红石榴石（Pyrope-Almandine）、红尖晶石与红宝石在偏光镜下都可能显示 ADR，无法单靠偏光镜区分，需结合折射仪、放大镜等其他工具。

### 7.8 翡翠（硬玉）与软玉

| 宝石 | 偏光镜反应 | 意义 |
|------|-----------|------|
| 翡翠（硬玉） | 全亮（AGG） | 微晶质集合体，天然标志 |
| 软玉（和田玉） | 全亮（AGG） | 微晶质集合体 |
| 染色翡翠 | 全亮（AGG） | 结构不变，但可能见染料集中于裂隙 |
| B 货翡翠（酸洗充填） | 全亮（AGG） | 结构特征与天然翡翠相似 |

### 7.9 琥珀（Amber）

琥珀是**非晶质**有机宝石，理论上在正交偏光镜下应全暗，但几乎所有天然琥珀都会出现**异常双折射（ADR）**——由内应力、局部重结晶和微气泡造成微观结构不均匀所致，表现为旋转时出现不规则消光和异常干涉色。

#### 7.9.1 各产地琥珀偏光镜反应汇总

| 产地 | 不规则消光 | 异常干涉色 | 显著度 | 干涉色规则性 |
|------|-----------|-----------|--------|------------|
| **抚顺琥珀** | ✅ 有 | ✅ **显著** | **最强** | **有规则（鉴别关键）** |
| **多米尼加琥珀** | ⚠️ 部分有 | ⚠️ 有 | 中等 | 无规律 |
| **波罗的海琥珀** | ✅ 有 | ❌ 极少/无 | 弱 | — |
| **缅甸琥珀** | ✅ 有 | ❌ 极少/无 | 弱 | — |
| **墨西哥琥珀** | ⚠️ 部分有 | ⚠️ 弱 | 弱至中等 | 无规律 |
| **压制琥珀（二代）** | ✅ 强 | ✅马赛克/蛇带状 | **很强** | 边界生硬，碎块方向不一致 |
| **柯巴树脂** | ✅ 有 | ⚠️ 弱 | 弱 | 无规律 |

> **抚顺琥珀的独特之处**：同时具有"**不规则消光 + 显著且有规则的异常干涉色**"这一组合特征，为其他产地琥珀所不具备。其他产地（波罗的海、缅甸）仅有消光无显著干涉色；多米尼加琥珀有干涉色但不显著且无规律。（来源：搜狐《抚顺琥珀鉴别方法》，2017）

#### 7.9.2 压制琥珀的偏光镜特征

压制琥珀（Reconstituted Amber）由小块碎料经加压加温熔结而成，各碎块原始偏振方向不同，偏光镜下可见明显的**颗粒边界**和方向不一致的应力区：

| 特征 | 天然琥珀 | 压制琥珀 |
|------|---------|---------|
| ADR 强度 | 弱至中等 | **强得多** |
| 消光形态 | 自然柔和的斑块 | **马赛克状（Mosaic）、蛇带状（Serpentine）**，边界清晰生硬 |
| 干涉色过渡 | 均匀柔和 | **生硬突变** |
| 应力纹理 | 均匀 | 不同碎块方向不同，碎裂状/流动状 |
| 假干涉图 | 极少 | 常见扭曲似糜棱状 |

> **来源：华东理工大学学报《琥珀、柯巴树脂及其改善品的谱学特征》（2019）**
> - YZ-1：明暗不规则连接，颜色生硬过渡 → **马赛克状**
> - YZ-3：蛇带状消光，界面沿血丝分布 → **蛇带状（血丝处理）**
> - YZ-4：扭曲似糜棱状异常彩色消光 → **深度处理**

> **注**：柯巴树脂偏光镜反应与天然琥珀高度相似，无法单靠偏光镜区分，需乙醚滴定辅助（柯巴软化，琥珀无反应）。

### 7.10 托帕石（Topaz）

托帕石是典型的二轴晶宝石：

| 特征 | 表现 |
|------|------|
| 偏光反应 | 四明四暗（DR） |
| 干涉图 | 二轴晶干涉图，有两个光轴方向 |
| 光性 | 二轴晶，可正可负 |
| 多色性 | 强多色性（偏光镜亮位下旋转可见颜色变化） |

### 7.11 锆石（Zircon）

锆石具有极高的双折射率（0.038-0.059），是偏光镜下最易观察双折射的宝石之一：

| 特征 | 表现 |
|------|------|
| 偏光反应 | 四明四暗（DR），但即使微小刻面也可见明显的明暗分离 |
| 干涉图 | 单轴晶干涉图，色圈间距宽（因高双折射） |
| 特别提示 | 宝石必须侧放（亭部朝上），台面朝下会因高折射率导致全内反射，无法测试 |
