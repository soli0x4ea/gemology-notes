## 特殊说明文件

- **charoite.txt** — 紫硅碱钙石（查罗石）：该矿物为纳米级多矿物交生体，无可靠单晶结构数据
- **opal.txt** — 欧泊：非晶质（准矿物），由150–400 nm非晶SiO₂球粒规则堆积产生变彩，无晶体结构

## 缺失说明

- **塔菲石（Taaffeite, Mg₃BeAl₈O₁₆）**：因结构极其复杂且公开精确坐标数据有限，暂未生成CIF，待后续补充

## CIF格式说明

所有CIF文件采用P1惯例（P1 override），即晶胞内所有原子坐标显式列出，`_symmetry_space_group_name_H-M`设为`'P 1'`，真实空间群信息保存在`_symmetry_original_H-M`字段中。这种格式便于JavaScript解析器直接读取和渲染，无需执行对称操作扩展。

文件标准字段：
- `_cell_length_a/b/c` — 晶胞边长（Å）
- `_cell_angle_alpha/beta/gamma` — 晶轴夹角（度）
- `_cell_formula_units_Z` — 晶胞内化学式单元数
- `_symmetry_original_H-M` — 真实Hermann-Mauguin空间群符号
- `_symmetry_original_Int_Tables_number` — 国际晶体学表空间群编号
- `_atom_site_*` — 原子坐标（分数坐标x,y,z，占位率occupancy）
- `_citation_*` — 数据来源文献
